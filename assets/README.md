# Local avatar assets

Character GIFs and MP3 themes are intentionally excluded from Git. The monitor reads them from `assets/<name>/` on your machine. Each avatar needs `idle.gif`, `running.gif`, `waving.gif`, `waiting.gif`, and `failed.gif`, or an `animations.json` whose state mappings resolve to available GIFs. Optional `variants.json` lists `working` scenes (8–14 second rotation), `thinking`/`reading` scenes (12–20 seconds), `delegating` scenes (10–16 seconds), `background` scenes (25–45 seconds), and an optional `busy_shift` one-shot (30-second cooldown). Idle/picker and approval/error poses remain fixed. Optional `music.json` lists `field`, `battle`, `boss` and `victory` music files in the same folder; see the main README.

The included animation profiles document the local characters used for development. On a fresh clone, copy your own GIFs into these directories or register another asset directory with `python3 scripts/monitor.py add-avatar NAME DIRECTORY`. See the root README for setup.
